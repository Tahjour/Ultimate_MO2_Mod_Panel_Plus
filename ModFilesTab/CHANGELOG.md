# Список изменений (Changelog)

## [2026-02-26] — Исправление визуализации конфликтов и ShellExecute

### Исправления в ESP Viewer
*   **Исправление "All plugins"**:
    *   **Подсветка текущего плагина**: Реализован `StructureHeaderView` — кастомный заголовок, который гарантированно подсвечивает столбец текущего плагина синим фоном и белым жирным шрифтом, обходя ограничения стандартных стилей Windows.
    *   **Отображение текущего плагина**: Исправлена ошибка, из-за которой текущий открытый плагин мог отсутствовать в списке сравнения во вкладке "All plugins".
    *   **Устранение пустых полей**: Исправлена проблема пустого первого столбца ("Field"). Добавлены проверки на пустые сигнатуры в `_field_label` и реализован механизм фоллбека (откат к ключу узла или "Unknown Field") в `_display_structure_data`.
    *   **Чистка кода**: Удалена устаревшая логика подсветки заголовков через `setHeaderData`, замененная на более надежный `StructureHeaderView`.
*   **Визуализация заголовков**: Доработан `HeaderHighlightDelegate` для `structure_view`.
    *   Исправлена проблема игнорирования системными стилями Windows фонового цвета заголовков (теперь используется прямое обращение к `model.headerData`).
    *   **Жирный шрифт**: Реализована принудительная отрисовка текста жирным шрифтом для заголовка текущего плагина.
    *   Улучшена контрастность подсветки (opacity слоя увеличена до 0.3).
*   **Устранение критических runtime-ошибок**:
    *   Исправлен `NameError: QSize` в `main_window.py` (добавлен отсутствующий импорт из `PyQt6.QtCore`).
    *   Исправлен `NameError: logger` в `ModFilesTab/__init__.py` (инициализирован стандартный логгер `logging.getLogger(__name__)`).
*   **Устранение ShellExecute Error 5**:
    *   В `ModFilesTab/__init__.py` заменен вызов `QDesktopServices.openUrl` на внутренний запуск `esp_viewer` для файлов плагинов. Это предотвращает ошибку "Access Denied" при попытке открытия системным обработчиком.
    *   В `conflict_analyzer.py` добавлена нормализация путей через `os.path.normpath` для корректной обработки путей из `ModOrganizer.ini` со смешанными слешами.
*   **Оптимизация импортов**: Исправлена логика динамического импорта `esp_viewer` внутри `ModFilesTab`, обеспечена корректная работа подпакетов при запуске из MO2.
*   **Чистка кода**: Удалена дублирующаяся функция `_read_game_data_from_mo_ini` в `conflict_analyzer.py`.

## [2026-02-25] — Оптимизация и стабильность

### Изменения в ESP Viewer
*   **Оптимизация поиска по FormID**: Добавлен `record_map` в `PluginFile` для мгновенного доступа к записям. Сложность поиска снижена с $O(M)$ до $O(1)$, что полностью устранило подвисания UI при переключении между записями конфликтов.
*   **Ускорение инициализации**: `FormIDResolver` теперь повторно использует построенный индекс из `PluginFile` вместо повторного сканирования всего плагина.
*   **Оптимизация загрузки**: В `PluginLoaderThread` отключено построение избыточных путей к записям (`build_record_paths`), что сократило время инициализации больших плагинов (напр. `Skyrim.esm`).
*   **Исправление пустых столбцов**: В `ModFilesTab` исправлена проблема с появлением пустого столбца после заголовка "Field" в просмотре структуры записей.
*   **Улучшенная загрузка цепочки плагинов**: Теперь для загрузки мастер-плагинов в `_load_chain_plugin` используются абсолютные пути из `RecordConflict.chain_paths`, что обеспечивает стабильную работу даже при нахождении плагинов в разных директориях.
*   **Надежность**: Добавлена логика фоллбека для поиска плагинов в директории текущего плагина, если путь в цепочке не найден.
