# ModFilesTab — Плагин для Mod Organizer 3 (MO3)

**ModFilesTab** — это многофункциональный плагин для Mod Organizer 3, предназначенный для расширенного управления файлами модов, их предпросмотра и глубокого анализа плагинов игры (Skyrim, Fallout и др.).

## 🚀 Основные возможности

### 1. Предпросмотр файлов в MO3
Плагин встраивается как отдельная вкладка в Mod Organizer 3 и позволяет быстро просматривать содержимое файлов выбранного мода:
*   **BSA/BA2**: Просмотр списка файлов внутри архивов Bethesda.
*   **NIF**: Предпросмотр 3D-моделей (NetImmerse/Gamebryo).
*   **HKX**: Просмотр данных анимаций Havok.
*   **PEX**: Декомпиляция и просмотр скриптов Papyrus.
*   **DDS**: Отображение текстур с выбором каналов (RGBA).
*   **Текстовые файлы**: Просмотр конфигураций (.ini, .txt, .xml, .json) с подсветкой.

### 2. ESP Viewer — Анализ игровых плагинов
Интегрированный инструмент для детального изучения файлов `.esp`, `.esm`, `.esl`.
*   **Дерево рекордов**: Просмотр иерархии групп и записей плагина.
*   **Анализ конфликтов**: Сравнение данных текущего плагина с мастерами и перекрывающими модами.
*   **Структура записи**: Отображение полей записи (Field) и их значений из всех плагинов в цепочке загрузки.
*   **Продвинутый поиск**: Фильтрация по Signature, FormID, EditorID и Full Name.
*   **Экспорт**: Возможность выгрузки данных в форматы CSV, JSON, HTML, XML, Lua и др.

## 📂 Детальное описание структуры файлов

### 🔹 Корневая директория (Интеграция с MO3)
*   **`__init__.py`**: Основной файл плагина MO3. Содержит класс, реализующий интерфейс `mobase.IPluginTab`. Отвечает за создание UI вкладки, обработку событий выбора мода и запуск ESP Viewer.
*   **`bsa_preview.py`**: Логика извлечения списка файлов и предпросмотра содержимого BSA/BA2 архивов.
*   **`nif_preview.py`**: Интеграция просмотрщика NIF-файлов (использует QOpenGLWidget для рендеринга).
*   **`hkx_preview.py`**: Обработка и визуализация данных анимационных файлов Havok.
*   **`pex_preview.py`**: Простейший декомпилятор и вьюер байт-кода скриптов Papyrus.

### 🔹 Модуль `esp_viewer/core/` (Бизнес-логика)
*   **`data_types.py`**: Определение базовых структур данных: `PluginFile`, `Group`, `Record`, `Field`. Включает оптимизированный `record_map`.
*   **`plugin_file.py`**: Основной парсер плагинов. Использует `mmap` для ленивого чтения и строит индекс записей.
*   **`conflict_analyzer.py`**: Алгоритм анализа конфликтов. Сравнивает записи в цепочке плагинов и определяет статуи конфликтов (Winner, Loser, Conflict).
*   **`formid_resolver.py`**: Утилита для разрешения FormID в человекочитаемые названия (EditorID, FullName) с учетом мастер-файлов.
*   **`load_order.py`**: Логика определения порядка загрузки плагинов на основе данных из Mod Organizer 3.
*   **`record_parser.py`** и **`group_parser.py`**: Низкоуровневые парсеры для разбора бинарной структуры записей и групп.
*   **`localization.py`**: Поддержка строк из `.STRINGS`, `.DLSTRINGS`, `.ILSTRINGS` файлов для локализованных плагинов.
*   **`search_engine.py`**: Движок поиска по записям с поддержкой различных критериев фильтрации.

### 🔹 Модуль `esp_viewer/ui/` (Интерфейс)
*   **`main_window.py`**: Главное окно ESP Viewer. Координирует работу всех виджетов и управляет загрузкой плагинов.
*   **`loader_thread.py`**: Фоновый поток для неблокирующей загрузки и парсинга тяжелых плагинов.
*   **`search_widget.py`**: Панель быстрого поиска и фильтрации записей.
*   **`advanced_search_widget.py`**: Расширенный поиск по сложным критериям (диапазоны FormID, содержимое полей).
*   **`tools_panel.py`**: Боковая панель с дополнительными инструментами и информацией о плагине.
*   **`export/`**: Подсистема экспорта.
    *   `export_dialog.py`: Диалоговое окно настройки экспорта.
    *   `export_thread.py`: Выполнение экспорта в фоновом режиме.

### 🔹 Модуль `esp_viewer/formatting/` (Визуализация данных)
*   **`record_formatter.py`**: Преобразование сырых бинарных данных записи в дерево объектов `DetailNode` для отображения в UI.
*   **`value_formatter.py`**: Специфическое форматирование отдельных типов данных (флаги, перечисления, цвета).
*   **`group_formatter.py`**: Форматирование заголовков групп для дерева навигации.

## ⚙️ Технические особенности и оптимизации

*   **Высокая производительность**: Использование `mmap` для быстрого доступа к данным без полной загрузки файлов в память.
*   **Мгновенный поиск**: Использование `record_map` ($O(1)$) для доступа к записям по FormID.
*   **Многопоточность**: Разделение UI и тяжелых вычислительных задач (загрузка, экспорт).
*   **Ленивая загрузка**: Детальная структура записи парсится только в момент её выбора пользователем.

## 🛠 Установка и настройка

1.  Скопируйте папку `ModFilesTab` в директорию `plugins` вашего экземпляра Mod Organizer 3.
2.  Убедитесь, что у вас установлен Python (рекомендуется 3.12+).
3.  Для работы ESP Viewer могут потребоваться зависимости: `PyQt6`, `mmap`.
4.  В настройках плагина в MO3 можно указать путь к конкретному интерпретатору Python (`espViewerPythonPath`).
